# SGA Studio

Personal Makeup Business Manager — aplikasi pribadi untuk mengelola klien, booking, pembayaran, pemasukan, dan pengeluaran bisnis MUA.

Data tersimpan lokal di browser/HP (tidak dikirim ke server). Gunakan menu Pengaturan → Backup secara rutin.

## Pasang di HP Android
1. Buka alamat GitHub Pages repo ini di Chrome.
2. Menu ⋮ → **Instal aplikasi** / **Tambahkan ke layar utama**.

## Update aplikasi
Ganti isi `index.html`, lalu naikkan nomor versi `sga-studio-v1` di `sw.js` (misal `v2`) agar HP mengambil versi terbaru.
